# Runtime opcional de fala

Execute `npm run setup:speech` na raiz do projeto. O script compila a revisão fixada de whisper.cpp para a arquitetura local e verifica o SHA-256 do modelo. Os executáveis e pesos não pertencem ao Git.

Os avisos nesta pasta devem ser mantidos na distribuição correspondente. Consulte `../SPEECH.md` e `../../THIRD_PARTY_NOTICES.md`.
