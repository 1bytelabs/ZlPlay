# Identidade ZLPlay

O símbolo aprovado combina pistas e controles de áudio com recortes ZL. Paleta: roxo #7C3AED, violeta #8B5CF6 e lilás #B88AF4 sobre fundo #0D111C.

- approved-concept.png: apresentação original aprovada, criada com a ferramenta de geração de imagens.
- ../../app/brand/zlplay-mark.svg: matriz vetorial limpa redesenhada a partir do conceito aprovado, com transparência e gradientes. Use essa matriz para exportações futuras.
- ../../desktop/icon.png: exportação 1024 × 1024 transparente usada pela janela e disponível para empacotamento macOS.
- ../../desktop/icon.ico: Windows, tamanhos 16, 24, 32, 48, 64, 128 e 256.
- ../../app/favicon.svg: mesma identidade no navegador.
- ../../app/brand/1byte-labs.svg: autoria, exibida apenas em Sobre.

## Aplicar no macOS

Atualize a branch main e mantenha esses arquivos ao integrar as alterações do macOS. A configuração mac.icon já aponta para desktop/icon.png. Gere o pacote macOS no ambiente macOS e confira o ícone no Finder/Dock. Este commit não gera nem publica instalador macOS.

A imagem de conceito foi gerada a partir do pedido de um símbolo compacto com pistas, controles de mixer e recortes ZL, em roxo/lilás sobre azul escuro. O arquivo vetorial é a matriz de produção; a apresentação não deve ser usada como ícone. A pesquisa visual inicial não constitui garantia de exclusividade de marca.
