# ZLPlay — orientações para agentes

Para pedidos de preparação ou publicação de releases, leia primeiro [docs/releases/PUBLICACAO-WINDOWS.md](docs/releases/PUBLICACAO-WINDOWS.md).

Atualização vigente: a pedido do usuário, Windows 2.8.1 e Mobile 0.11.1 serão publicados em uma nova release `v2.8.1`. Preserve integralmente a release/tag `v2.8.0`. O Mac será atualizado em seu próprio ambiente e anexado à mesma v2.8.1; consulte `docs/releases/HANDOFF-MAC-2.8.1.md`. As orientações abaixo sobre 2.8.0 são históricas e não impedem a nova release expressamente autorizada.

O usuário decidiu publicar macOS primeiro e acrescentar Windows à mesma release `v2.8.0`. Ao receber o pedido de publicar Windows, use o repositório existente `1bytelabs/ZlPlay`, preserve os assets e notas do Mac e acrescente os executáveis Windows. Não crie outro repositório ou uma release duplicada.

Siga também `CONTRIBUTING.md` para compilar, testar e auditar alterações. Preserve trabalho local e mudanças específicas de cada plataforma.
